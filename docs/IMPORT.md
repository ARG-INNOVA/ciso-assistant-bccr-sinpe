# Future CISO Assistant import plan

No importable library is supplied. `framework/metadata.json` is project status data, not an import format. The Markdown templates are drafting aids only.

Before generating Excel or YAML:

1. Consult the [upstream repository](https://github.com/intuitem/ciso-assistant-community) and the documentation associated with the selected version.
2. Record the release/commit, library format, required fields, supported identifiers and documented import/conversion procedure.
3. Build draft artifacts from the reviewed requirement inventory; preserve source traceability and licensing boundaries.
4. Validate the actual schema and semantics with version-appropriate tooling.
5. Import in an isolated test instance and record logs, hierarchy, counts and any corrections.
6. Complete [release review](VALIDATION.md) before moving reviewed artifacts into `framework/releases/`.

No conversion command or workbook v2 schema is asserted here because neither has been selected or tested. Upstream submission is a later step subject to its contribution requirements and review; this scaffold is not an accepted upstream library.
