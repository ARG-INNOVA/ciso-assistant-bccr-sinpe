# Contributing

Keep Spanish and English aligned. Cite the exact source section and PDF page for every requirement. Preserve the 47 official control IDs and source wording; label all procedural subdivisions and interpretation as editorial. Use letter suffixes for source-derived subdivisions and retain existing released IDs when possible.

Do not turn definitions, optional permissions or BCCR regulatory powers into mandatory entity checklist actions. Preserve conditions, deadlines, exceptions and scope. Checklist questions drive result without numeric `add_score`; only conditional items may offer Not applicable. Do not use zero weights to claim exclusion from scoring.

Run `python3 -m pip install -r scripts/requirements-validation.txt` and `python3 scripts/validate_scaffold.py`. Explain the source, behavioral changes and checks in a pull request. Record actual application version and import evidence when available. External consultant review is optional, not a mandatory gate.

Preserve the scoped MIT license and third-party exclusions. Identify provenance and the applicable project authorization for third-party material; do not grant MIT over regulatory content. No confidential assessments or customer data.

Upstream inclusion requires a separate pull request reviewed by Intuitem. Commercial presentation on this repository does not guarantee acceptance upstream.
